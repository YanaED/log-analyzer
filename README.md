# Анализатор лог-файлов

Веб-приложение для загрузки, анализа и визуализации лог-файлов.  
Дипломный проект на стеке **Python + Dash + MongoDB**.

## Возможности

- Загрузка логов (`.log`, `.txt`, `.json`, `.csv`, `.xlsx`)
- Парсинг и сохранение в MongoDB
- Фильтрация по дате/времени, IP, статусу, уровню, тексту
- Графики: временной ряд, уровни, HTTP-статусы, география IP, топ URL и др.
- Поиск аномалий (Isolation Forest)
- Экспорт в CSV, JSON, PDF
- Регистрация/вход пользователей, подтверждение e-mail (SMTP)
- Журнал аудита для администратора

## Требования

- Python 3.8+
- MongoDB 4.4+

## Установка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/YanaED/diplom.git
cd diplom
```

2. Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate

pip install -r requirements.txt
```

3. Скопируйте настройки окружения:

```bash
# Windows
copy .env.example .env

# Linux / macOS
cp .env.example .env
```

Отредактируйте `.env`: задайте `APP_SECRET_KEY`, при необходимости `ADMIN_EMAIL` и SMTP.

4. Запустите MongoDB и проверьте подключение:

```bash
# Windows
net start MongoDB

python check_mongodb.py
```

## Запуск

```bash
python main.py
```

Откройте в браузере: http://127.0.0.1:8050

## Кратко об использовании

1. Зарегистрируйтесь и войдите (если SMTP не настроен — аккаунт активируется сразу).
2. На вкладке загрузки загрузите лог-файл.
3. На вкладке «Просмотр данных» выберите коллекцию и загрузите записи.
4. Используйте фильтры, графики, поиск аномалий и экспорт.

## Конфигурация

Основные параметры — в `config.py` и `.env`:

| Переменная | Назначение |
|---|---|
| `APP_SECRET_KEY` | Секрет сессий |
| `ADMIN_EMAIL` | E-mail с доступом к аудиту |
| `APP_HOST` / `APP_PORT` | Хост и порт приложения |
| `MONGO_*` | Подключение к MongoDB |
| `SMTP_*` | Почта для подтверждения регистрации |
| `PUBLIC_APP_URL` | URL для ссылок в письмах (LAN) |
